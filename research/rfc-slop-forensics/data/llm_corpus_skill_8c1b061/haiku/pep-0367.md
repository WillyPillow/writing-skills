# PEP 367: New Super

## Summary

This PEP proposes a shorter syntax for calls to the `super` type. Instead of writing `super(Foo, self).foo(1, 2)`, the programmer would write `super.foo(1, 2)`. The new form would construct the super object automatically, bound to the class in which the method was defined and to the instance that the method is currently acting on. In a classmethod, the bound object would be the class rather than an instance.

The PEP also proposes two changes to the existing builtin. The current `__builtin__.super` would be aliased to `__builtin__.__super__`, and `__builtin__.super` would be removed in Python 3.0. Assignment to `super` would become a `SyntaxError`, which the material compares to the way Python already treats `None`.
