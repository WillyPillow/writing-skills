# PEP 520: Preserving Class Attribute Definition Order

## Abstract

This PEP changes the class definition so that the order in which attributes are introduced in the class body is preserved. The order is stored in a `__definition_order__` attribute of the class. This lets code introspect the original definition order, for example by iterating over the class's attributes in the order they were written. ## Rationale

The chosen design records the order at class creation, not at lookup time. Recording at creation is the only point at which the order is known for certain. [TODO: state whether a lookup-time reconstruction was considered and why it lost.]

Using a single attribute on the class keeps the information in one place, where a reader already looks for class metadata. [TODO: state the deciding reason for a dunder attribute over a separate registry, if one was considered.]
