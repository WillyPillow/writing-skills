## Abstract

This PEP proposes to deprecate `codecs.StreamReader` and `codecs.StreamWriter`. The two classes overlap with `io.TextIOWrapper` and `codecs.StreamReaderWriter`, and keeping both sets of implementations means that bugs get fixed twice.

## History

The `codecs` module was introduced in Python 2.0. It provided a registry of codecs and the stream classes built on them. The `io` module was introduced in Python 2.6 and 3.0. The `io` module was reimplemented in C in Python 2.7 and 3.1. [TODO: confirm the reference to the PEP that introduced `io`, which is cited in the source material and must be supplied in full.]
