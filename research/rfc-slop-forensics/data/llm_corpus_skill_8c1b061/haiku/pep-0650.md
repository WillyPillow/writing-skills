## Problem

The material's central observation is that the lack of a standard requirements file makes the installers hard to combine. Each tool can install dependencies only from the format it defines. A user who wants another installer to handle the same project has two options, according to the material. The first is to use the original tool. The second is for the tool to emit a requirements file in a form the other installer can read.
