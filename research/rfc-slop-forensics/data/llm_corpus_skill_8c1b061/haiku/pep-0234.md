# PEP 234: Iterators

## Summary

This document proposes an iteration interface that objects can provide to control the behavior of `for` loops. A loop is customized by a method that returns an iterator object. The iterator provides a get-next operation. Each call returns the next item in the sequence, and the operation raises an exception when no items remain.

The document also proposes two specific iterators: one over the keys of a dictionary, and one over the lines of a file. It proposes that `dict.has_key(key)` may be written as `key in dict`.
