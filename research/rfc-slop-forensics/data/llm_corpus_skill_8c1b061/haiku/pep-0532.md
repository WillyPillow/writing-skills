# PEP 532: A circuit breaking protocol and binary operators

## Summary

This PEP proposes a circuit breaking protocol, defined by two method names, `__then__` and `__else__`. The protocol is meant to give one shared semantic base to five constructs: conditional expressions (`LHS if COND else RHS`), logical conjunction (`LHS and RHS`), logical disjunction (`LHS or RHS`), the None-aware operators proposed in PEP 505, and the rich comparison chaining model proposed in PEP 535.

Building on the protocol, the PEP proposes that conditional expressions be extended so that `if` and `else` also work as general short-circuiting binary operators. `if` would be right-associative (`LHS if RHS`), and `else` would be left-associative (`LHS else RHS`).
