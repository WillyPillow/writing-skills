## Abstract

This PEP adds statically nested scoping, also called lexical scoping, to Python 2.2. It is also available as a source-level option in Python 2.1. In addition, Python 2.1 issues warnings about constructs whose meaning may change once the feature is enabled.

Before this change, the language defined exactly three namespaces for resolving names: the local namespace, the global namespace and the built-in namespace. Nested scopes add a fourth kind of resolution. An unbound local name can be resolved in the namespace of an enclosing function. The most visible consequence is that lambdas, and other nested functions, can refer to variables defined in the surrounding namespace.

## Motivation

Without nested scopes, a nested function cannot see the variables of the function that contains it. A lambda that needs a value from its surroundings must receive that value through a default argument. The default argument copies the value into the lambda's own namespace at the time the lambda is created. ## Proposal

When a name is not bound in the local namespace of a function, the name is resolved in the enclosing function's namespace, if there is one, before the global and built-in namespaces are consulted. ## Transition

The feature is introduced in two steps, which is why the PEP describes Python 2.1 as well as 2.2. In Python 2.1 the feature is a source-level option. The option is needed because enabling the feature can change what some existing programs mean. Python 2.1 therefore issues warnings for the constructs whose meaning changes, so that a programmer can find and check them before turning the feature on. ## Cost accepted

Resolving names through an additional namespace makes the rule for finding a name longer to state. Programs that relied on the old resolution must be checked when the feature is enabled. [TODO: state what else the authors give up, if anything.]

## Reversibility

The rule for resolving names is part of the language definition. Programs written against the new rule depend on it, so reverting the rule later would break them. The two-step transition is the authors' way of limiting that cost. [TODO: confirm this is the authors' reason for the two-step approach.]
