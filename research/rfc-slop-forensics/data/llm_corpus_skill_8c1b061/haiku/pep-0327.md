# PEP 327: Decimal Data Type

## Summary

This PEP proposes a Decimal data type for uses where decimal numbers are needed and binary floating point is too inexact. The type supports the standard functions and operations of Python. It complies with the decimal arithmetic standard X3.274-1996.

Decimal is floating point, not fixed point, and it has bounded precision: the precision is the upper limit on the number of significant digits in a result. The precision is settable by the user. The type also supports the notion of significant trailing zeroes, so that fixed-point usage is possible on top of the floating-point design.

The work is based on code and test functions written by Eric Price, Aahz and Tim Peters. ## Design

### Floating point with bounded precision

The type is floating point. A result is rounded to the precision the user has set. Because the precision is an upper limit on significant digits, the number of digits in a result can be smaller than the precision when a result does not need that many.
