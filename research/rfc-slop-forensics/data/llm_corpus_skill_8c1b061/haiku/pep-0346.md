# PEP 346: User Defined ("with") Statements

## Summary

This PEP combines two earlier proposals. From PEP 310 it takes reliable acquisition and release pairs. From PEP 340 it takes the anonymous block statement. The PEP blends the parts of PEP 340 that it judges useful with parts of PEP 310 and arranges them into a single statement. The material says the PEP borrows from several other PEPs, and it is written to stand on its own, so that a reader does not need to read those PEPs first.
