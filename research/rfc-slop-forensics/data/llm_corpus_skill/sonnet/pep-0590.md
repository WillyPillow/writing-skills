# PEP 590: Vectorcall: a fast calling protocol for CPython

## Abstract

This PEP introduces a new C API for optimizing calls of objects. It defines a "vectorcall" protocol and calling convention. The protocol builds on the "fastcall" convention that CPython already uses internally. Any user-defined extension class can use the new features. Most of the new API is private in CPython 3.8. The plan is to finalize the semantics and make the API public in Python 3.9.

This PEP deals only with the Python/C API. It does not affect the Python language or the standard library.
