# PEP 346: User Defined ("with") Statements

## Abstract

This PEP combines the "Reliable Acquisition/Release Pairs" of PEP 310 with the "Anonymous Block Statements" of PEP 340. It keeps the parts of PEP 340 that the author considers good, blends in parts of PEP 310, and rearranges them into one proposal. It borrows from other PEPs so that the picture is complete, and it is meant to be read without them.

## Context

Two earlier proposals address related needs.

PEP 310 concerns acquisition and release pairs. Its aim is that a resource, once acquired, is released reliably. PEP 340 concerns anonymous block statements, where a block of code is handed to a controlling object that decides how and whether to run it. [TODO: author to confirm these one-line descriptions from the PEP texts. The abstract gives only the section titles quoted above, and this draft draws no further conclusion about either PEP.]

The two proposals overlap in the area where a block of code runs between a setup step and a cleanup step. They differ in how much control they give the controlling object. ### Semantics

The statement has to define, at minimum, the following points.

1. What object controls the block and how the statement obtains it.
2. What runs before the block, and whether its result can be bound to a name.
3. What runs after the block when it ends normally.
4. What runs after the block when it ends by an exception, by `return`, by `break` or by `continue`.
5. Whether the controlling object can suppress an exception, replace it or run the block more than once.

Points 4 and 5 are where the two parent proposals differ most. A design that follows PEP 310 guarantees that release runs on every exit path. A design that follows PEP 340 lets the controlling object decide more. [TODO: author to state which behavior each point takes and which parent proposal it comes from. ## Open questions

1. The syntax.
2. The semantics of early exit from the block.
3. Whether the controlling object may run the block more than once.
4. The role of generators.
5. The differences from PEP 310 and PEP 340 that justify a third proposal.

The last question is the first one a skeptical reviewer will ask. If the two earlier proposals are each incomplete, the reviewer wants to know exactly what is missing. If one of them is adequate, the reviewer wants to know why it should not be adopted instead.
