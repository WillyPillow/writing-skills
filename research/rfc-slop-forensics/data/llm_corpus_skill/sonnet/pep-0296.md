# PEP 296: Adding a bytes Object Type

## Abstract

This PEP proposes a new standard type, `bytes`, and a builtin constructor of the same name. A `bytes` object is an array of bytes stored one byte per element. The PEP also lists characteristics that set `bytes` apart from the similar implementations already in use. ## Backwards Compatibility

Adding a builtin name can affect programs that already bind that name. A program that defines its own `bytes` at module level shadows the builtin and keeps working, but a program that relies on `bytes` being undefined, for example in a `try`/`except NameError` check, changes behavior.
