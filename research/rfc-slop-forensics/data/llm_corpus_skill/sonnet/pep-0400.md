# PEP 400: Deprecate codecs.StreamReader and codecs.StreamWriter

## Abstract

`io.TextIOWrapper` and `codecs.StreamReaderWriter` offer the same API. `TextIOWrapper` has more features and is faster than `StreamReaderWriter`. Duplicate code means that bugs must be fixed twice and that the two implementations may differ in subtle ways. This PEP proposes to deprecate `codecs.StreamReader` and `codecs.StreamWriter`.

## Background

The `codecs` module was introduced in Python 2.0 (see PEP 100). The `io` module was introduced in Python 2.6 and 3.0 (see PEP 3116) and was reimplemented in C in Python 2.7 and 3.1.

Two facts follow from these dates. The `codecs` stream classes are older than the `io` module. Since the `io` module exists, Python has two ways to wrap a byte stream and read or write text through an encoding. [TODO: confirm that this statement matches the author's intent.]
