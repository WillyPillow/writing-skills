## Abstract

This PEP introduces a new C API for optimizing calls to objects. It defines a new "vectorcall" protocol and calling convention. The convention is based on the "fastcall" convention, which CPython already uses internally. Any user-defined extension class can use the new features. Most of the new API is private in CPython 3.8, and the plan is to finalize its semantics and make it public in Python 3.9. The PEP deals only with the Python/C API. It does not affect the Python language or the standard library.
