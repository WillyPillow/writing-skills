## Abstract

This PEP specifies a tagging system that indicates with which versions of Python a built or binary distribution is compatible. A set of three tags indicates the Python implementation and language version, the ABI, and the platform that the distribution requires. The tags are kept terse because they are included in filenames.

## Motivation

A built distribution contains compiled code, and compiled code runs only on the interpreter, ABI and platform for which it was built. A tool that installs a distribution must therefore know whether the distribution will run on the current system before it installs it. ## Rationale

The tags are separate because the three components vary independently. A distribution may be compatible with one interpreter version and not another, while sharing its ABI and platform with the other.
