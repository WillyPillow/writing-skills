## Abstract

File names, environment variables and command line arguments are defined as character data in POSIX. The C interfaces that carry them, however, accept arbitrary bytes, whether or not those bytes follow any particular encoding. This PEP proposes a way to deal with such irregular bytes by embedding them in character strings, in a form that allows the original byte string to be recreated.

## Motivation

The problem begins with a mismatch between two definitions. POSIX calls these values characters, but the operating system and the C interfaces do not enforce that. A program that receives a file name therefore may receive a sequence of bytes that does not decode under the encoding the program expects. ## Reversibility

Once a program stores embedded names, for example in a database or in a file that other tools read, the embedding becomes part of the stored data. Changing the embedding later would then require conversion of every stored name. The abstract does not say whether programs will store these strings.
