## Abstract

The class io.TextIOWrapper and the class codecs.StreamReaderWriter offer the same API. TextIOWrapper has more features and is faster than StreamReaderWriter. This PEP proposes to deprecate codecs.StreamReader and codecs.StreamWriter, which are the two classes that codecs.StreamReaderWriter combines. [TODO: confirm this description against the final text. ## Motivation

Two modules now provide the same kind of object. The codecs module was introduced in Python 2.0. The io module was introduced in Python 2.6 and 3.0, and it was reimplemented in C in Python 2.7 and 3.1. Both modules therefore exist side by side, and the codecs classes are the older of the two.
