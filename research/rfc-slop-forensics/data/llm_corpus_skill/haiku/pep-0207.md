## Abstract

This PEP proposes several new features for comparisons. The first feature allows each of the operators <, >, <=, >=, ==, and != to be overloaded separately, both in classes and in C extensions. The second allows any of those overloaded operators to return a result other than a Boolean.

## Motivation

The comparison operators are a single mechanism in the current language, and a type that defines one of them cannot make the others behave differently. ## Rationale

The proposal separates the operators so that each can be given its own behavior. The abstract's first feature requires that the separation apply in classes and in C extensions.
