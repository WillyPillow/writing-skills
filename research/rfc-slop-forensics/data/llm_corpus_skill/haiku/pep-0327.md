## Abstract

The proposal is a `Decimal` data type for uses where decimal numbers are needed and binary floating point is too inexact. The type supports the standard Python functions and operations. The PEP says that the type must comply with the decimal arithmetic standard ANSI X3.274-1996, which the abstract cites as its reference [1]. [TODO: full citation for X3.274-1996, as the abstract cites it only by number.]

`Decimal` is floating point rather than fixed point, and it has bounded precision. The precision is the upper limit on the number of significant digits in a result. The precision is settable by the user. The type also supports the idea of a significant trailing zero, so that fixed-point usage is possible as well.

The abstract credits code and test functions written by Eric Price, Aahz and Tim Peters. It also states that the `decimal.py` reference implementation was moved into the standard library just before Python 2.4a1. [TODO: confirm the credit and the date from the author's records.]
