## Abstract

This PEP adds a new warning category, `EncodingWarning`. The warning is emitted when the `encoding` argument to `open()` is omitted and the default, locale-specific encoding is used. The warning is disabled by default. A new command-line option, `-X warn_default_encoding`, and a new environment variable, `PYTHONWARNDEFAULTENCODING`, enable it. The PEP also adds a `"locale"` value for the `encoding` argument. This value explicitly requests the locale encoding and silences the warning.

## Motivation

The `open()` function decodes and encodes text with an encoding that, when none is given, depends on the locale of the machine. [TODO: state the rule by which the default encoding is chosen on each platform, since the warning exists to make that dependence visible.]

The force is that code which depends on the locale can behave differently on different machines without any visible sign.
