## Context

## Proposal

This PEP proposes three changes.

1. Octal literals must now be written with a leading `0o` or `0O`, instead of a leading `0`.
2. Binary literals are supported, written with a leading `0b` or `0B`.
3. Provision is made for binary numbers in string formatting. [TODO: The formatting syntax the author proposes.]

## Timing

The changes target Python 3.0. The backward-compatible parts should also be added to Python 2.6. The aim is that every valid Python 3.0 integer literal is also valid in Python 2.6.
