## Abstract

The class definition syntax is ordered, so the attributes a class body defines are ordered. This PEP makes that order available outside the class definition. It records the order in which attributes are introduced in the class body and stores it in the `__definition_order__` attribute of the class. The abstract states that the information already exists in the class definition, so access to its order is a reasonable expectation. It also says that the order helps readability and is sometimes significant.
