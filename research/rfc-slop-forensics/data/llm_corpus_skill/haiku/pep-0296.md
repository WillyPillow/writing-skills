## Abstract

This PEP proposes a new standard type and a builtin constructor, both called `bytes`. A bytes object is an efficiently stored array of bytes. It has additional characteristics that set it apart from several similar implementations.

## Background

A byte is a value from 0 to 255. An array of byte values holds raw data, such as the contents of a file read in binary mode, where each element is one byte and not one character. The distinction matters because a program that treats raw data as text may decode it incorrectly, and a program that treats text as raw data may lose the characters it needs. The proposal concerns the second kind of storage: a container for byte values that is itself a standard type.
