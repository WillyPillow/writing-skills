# PEP 223: Change the Meaning of \x Escapes

Status: [TODO: status, author names and creation date]

## Abstract

This PEP changes `\x` escapes, in both 8-bit and Unicode strings, so that each one consumes exactly the two hex digits that follow it. The PEP views the change as correcting an original design flaw. It argues that the change gives clearer expression in every flavor of string, a cleaner Unicode story, better compatibility with Perl regular expressions, and minimal risk to existing code.
