Title: Adding A Statistics Module To The Standard Library
Status: Draft
Type: Standards Track
Created: 2013
Python-Version: 3.4

# Abstract

This PEP proposes adding a module to the Python standard library for common statistics functions such as mean, median, variance and standard deviation. See also http://bugs.python.org/issue18606.

# Rationale

Python is widely used for numerical and scientific work, and the scientific ecosystem built around NumPy, SciPy and pandas provides excellent statistical tools. However, a large number of Python users are not scientists. They are students, system administrators, web developers, analysts and hobbyists who need to compute an average or a spread of some numbers and have no wish to install and learn a large third-party package to do it.

For these users, the standard library offers almost nothing. They are left to write their own functions, and the functions they write are frequently wrong. The obvious implementations are numerically naive:

```python
def mean(data):
    return sum(data) / len(data)

def variance(data):
    m = mean(data)
    return sum((x - m) ** 2 for x in data) / len(data)
```

These have several problems:

- `sum()` on floats accumulates rounding error. For data with large magnitude and small spread the result can be noticeably wrong.
- The "computational formula" for variance that appears in many textbooks, `mean(x**2) - mean(x)**2`, suffers from catastrophic cancellation and can even return a negative variance.
- The naive variance above computes the population variance, but many users actually want the sample variance with Bessel's correction, and do not know the difference.
- They do not work on iterators, only on sequences.
- They mishandle `Decimal` and `Fraction` input, or mix them with floats in surprising ways.

A well-designed standard library module avoids all of these pitfalls once, for everyone, and documents the distinctions that matter.

## Why not just use NumPy?

NumPy is the right tool for large arrays and heavy numerical work, and nothing in this proposal is intended to compete with it. But NumPy is a large dependency, it is not always available (for example on some embedded or restricted platforms, or in teaching environments), and its functions are designed for arrays of machine floats. It is not the natural choice for computing the median of a list of `Fraction` values, or for a ten-line script that averages a log file.

There is also an educational argument. Python is a popular teaching language, including in introductory statistics courses. A small, readable module with clear documentation of what each function computes is valuable for teaching in a way a high-performance array library is not.

## Why not a recipe in the documentation?

Recipes get copied incorrectly, are not tested, and are not maintained. Correctly handling numeric types and precision takes more code than a recipe can comfortably hold.

# Design Goals

The module should:

- Be correct first. Accuracy matters more than speed.
- Cover the needs of what might be called "calculator-level" statistics: the functions found on a good scientific calculator, not those of a full statistics package.
- Accept any iterable, not just sequences.
- Work with `int`, `float`, `Decimal` and `Fraction`, and return a result of the appropriate type where that makes sense.
- Raise clear errors on invalid input, such as an empty data set.
- Have a small, easily understood API with no configuration.

The module is explicitly not intended to be a replacement for SciPy, R, SAS or similar. It will not include hypothesis testing, regression models or probability distributions in its initial version.

# Specification

The proposed module is named `statistics` and provides the following functions.

## Measures of central location

- `mean(data)`: the arithmetic mean. Computed using exact summation, so that the result is correctly rounded for floats and exact for `Fraction` and `Decimal`.
- `median(data)`: the middle value of the sorted data. When the number of data points is even, returns the mean of the two middle values.
- `median_low(data)` and `median_high(data)`: when the number of data points is even, return the lower or higher of the two middle values respectively. These are useful when the data is discrete and the result must be an actual data point.
- `median_grouped(data, interval=1)`: the median of continuous data grouped into class intervals, using interpolation. This is the form commonly taught in introductory statistics courses.
- `mode(data)`: the most common value. Works for non-numeric data too. Raises `StatisticsError` if there is no unique mode.

## Measures of spread

- `pvariance(data, mu=None)`: population variance.
- `variance(data, xbar=None)`: sample variance, using `n - 1` in the denominator.
- `pstdev(data, mu=None)`: population standard deviation, the square root of `pvariance`.
- `stdev(data, xbar=None)`: sample standard deviation.

The optional `mu` and `xbar` arguments allow a caller who has already computed the mean to avoid computing it again. They are not validated, and supplying an incorrect mean will give an incorrect result.

The variance functions use the two-pass algorithm with a compensating correction term, which is numerically stable for typical data.

## Exceptions

`StatisticsError`, a subclass of `ValueError`, is raised for invalid input, such as calling `mean()` on an empty iterable or `variance()` on fewer than two points.

## Implementation notes

Exact summation is achieved by converting each value to an exact `Fraction` (floats are exactly representable as fractions), summing exactly, and converting the result back to the appropriate type at the end. For `Decimal` input the result is a `Decimal`; for float input, a float; for `Fraction` input, a `Fraction`; and mixtures are coerced following the usual numeric tower, with `Decimal` and `float` refusing to mix.

This approach is slower than a naive `sum()`, but the module explicitly prioritises correctness, and it is fast enough for the data sizes its target users work with.

# Examples

```python
>>> from statistics import mean, median, stdev
>>> mean([1, 2, 3, 4, 4])
2.8
>>> median([1, 3, 5, 7])
4.0
>>> stdev([2.5, 3.25, 5.5, 11.25, 11.75])
4.38961843444...
>>> from fractions import Fraction as F
>>> mean([F(3, 7), F(1, 21), F(5, 3)])
Fraction(13, 21)
```

# Future Work

Once the module exists, natural extensions include additional averages (geometric and harmonic mean), quantiles, and simple bivariate functions such as correlation and linear regression. These are deliberately left out of this proposal to keep the initial scope focused and reviewable.

# Backwards Compatibility

This is a new module and does not affect existing code. Third-party packages named `statistics` will be shadowed by the standard library module only in the usual way governed by `sys.path`.
